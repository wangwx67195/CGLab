# CGLab · 计算机图形学项目式学习路线

> 版本：v1.0 · 制定日期：2026-10-27 · 状态：**规划，不代表课程已开始或已完成**
> 主线：GAMES101 公开课程（2020 年，22 讲）；将其知识点重新组织为 28 节“原理 + 独立编程 + 验证”的实验课。**不是 GAMES101 官方教学计划**。

## 0. 课程定位

学习者为计算机专业研究生，希望补全图形学算法基础，在数学推导、数据结构、CPU 实现、测试与解释之间建立联系。已有一定编程背景，但不假定图形学基础或熟练 C++ 工程能力。

长期目标：能够**不依赖图形学黑盒 API**，解释并逐步实现一个小型 CPU 渲染/仿真系统，并具有继续学习实时渲染、几何处理、数字人和动画技术的基础。

- **主语言与构建**：C++17、CMake、Git；先只用 C++ 标准库，之后按需引入 Eigen3（不得用 Eigen 直接替代本课必须自己推导的算法）。
- **可视化**：前期用 PPM 文件输出图像，不要求 GUI、OpenGL、Vulkan 或 CUDA。后期可选择图像库 / 窗口库，但属于工具层。
- **每节课**：一个有意义的算法主题、一个自己编写的可运行实验、至少一种可检验的结果；正常建议 2–4 小时，复杂主题允许跨多次学习会话，但不拆成“专门教一个 API”的课。
- **节奏**：建议每周 1–2 节，约 14–28 周，不设硬性工期。未通过验收则不自动推进；卡住时调整同一节课的难度或增加针对性补充练习，不改变主题编号。
- **必做/挑战**：每课核心目标必做，扩展挑战自由选择。若耗时较长，先完成核心再进入下一课。
- **禁止代写**：Agent 不直接提供整段可运行的核心算法实现；见 `docs/AGENT_TEACHING_GUIDE.md`。

## 1. 每节课的标准节奏

1. **目标**：用实际现象提出问题（如“为什么后画的三角形不一定挡住先画的？”）。
2. **直觉 → 数学**：先举小规模数值例子，再明确符号、坐标系、向量/矩阵维度、边界条件。
3. **实现路线**：拆分输入、核心数据结构、需自己写的函数、API 提示、输出与验收条件；不给整份答案。
4. **亲手实现**：学生动手，Agent 只在请求时给予分级提示、局部错误定位和测试建议。
5. **检验**：至少一个正常例子、一个边界例子、一个简短解释；尽量保存结果截图/图片和命令。
6. **记录**：经验证后依据 `docs/PROGRESS_MAINTENANCE.md` 更新进度、疑点、下一步。

## 2. 28 节完整路线（核心目标）

### A. 从像素到基本变换（L01–L06）

| 课次 | 完整主题 | 自己实现的可运行产物 | 核心验收点 | GAMES101 对应 |
|---|---|---|---|---|
| **L01** | **CPU 帧缓冲：计算机如何生成一张图？** | 256×256 RGB 渐变 + 指定几何区域的 PPM 图片 | 像素顺序、四角颜色、文件头、越界行为 | Lecture 01、05；作业 0 的工具准备（非等价于原作业） |
| L02 | 向量计算与几何判定 | 二维向量、点线侧向关系的可视化小程序 | 点积/叉积的几何意义、零向量、浮点误差 | Lecture 02 |
| L03 | 二维齐次变换与层级模型 | 平移、缩放、旋转的 2D 线框场景 | 先旋转后平移与相反顺序的差异 | Lecture 03 |
| L04 | 三维相机与 MVP 变换 | 可改变视角的线框立方体投影成 2D 图像 | 坐标系、矩阵顺序、透视除法、近平面约定 | Lecture 03–05；作业 1 |
| L05 | 三角形光栅化 | 把两个屏幕空间三角形真正填充为像素 | 像素中心采样、边函数、绕序、边界规则 | Lecture 05；作业 2 |
| L06 | 深度缓冲与遮挡 | 先后绘制顺序不改变正确遮挡关系的场景 | Z-buffer 初始化、深度比较方向、覆盖问题 | Lecture 06；作业 2 |

**阶段里程碑 A**：能解释并实现 `模型点 → 屏幕点 → 三角形像素`，输出一个正确处理遮挡的小图像。

### B. 着色、插值与纹理（L07–L12）

|---|---|---|---|---|
| L07 | 超采样抗锯齿 | 同一三角形 1× 与 2×/4× SSAA 对照图 | 子采样位置、平均颜色、性能成本 | Lecture 06；作业 2 |
| L08 | 重心坐标与透视正确插值 | 三角形内部平滑颜色，比较线性与透视正确 UV | 重心权重和为 1、除以 `w` 的必要性 | Lecture 08–09；作业 3 |
| L09 | 漫反射与 Blinn–Phong 光照 | 球体/简单网格的逐像素光照效果 | 法线归一化、光线方向、环境/漫反射/高光 | Lecture 07；作业 3 |
| L10 | 纹理映射与采样 | 带纹理的倾斜矩形/网格 | UV 坐标、最近邻与双线性、边界策略 | Lecture 08–09；作业 3 |
| L11 | 着色频率与完整软件流水线 | 同一模型 Flat / Gouraud / Phong 三种效果 | 三种插值/着色位置区别、图像比较 | Lecture 07–09；作业 3 |

**阶段里程碑 B**：完成可以读取少量顶点数据、投影、深度测试、插值、上色的基础 CPU Rasterizer。

### C. 几何表示与曲面（L13–L16）

| 课次 | 完整主题 | 自己实现的可运行产物 | 核心验收点 | GAMES101 对应 |

## 3. 可选挑战（不会阻碍推进）

- 光栅化：视锥裁剪、Top-left rule、MSAA 与 SSAA 的差异、Mipmap。
- 几何：细分曲面、简单网格光滑/降采样、空间哈希。
- 渲染：MIS、环境贴图、景深以外的运动模糊、简单降噪、并行加速。
- 动画：IK、Verlet/PBD、简化布料与碰撞。
- 工程：SDL/GLFW 实时窗口、OpenGL/Vulkan、CPU 多线程、性能分析。

这些内容与原 GAMES101 正课不完全一一对应；若要进入更深入的实时渲染、几何处理、物理仿真，可在课程结束后再安排专题。

## 4. 必须先统一的约定

- `x` 向右、图像数组 `y` 向下，原点默认左上角；图形学 NDC/相机坐标的轴方向需**另行在该课明确**，绝不混用。
- 图像 pixel `(x, y)` 一般以中心 `(x+0.5, y+0.5)` 采样；数组布局 `index = (y*width + x)*channels`。
- 使用**列向量、左乘**时 `p_clip = P * V * M * p_model`；如采用其他约定必须统一文档及测试。
- `w` 透视除法和 `z` 的深度范围/符号由当前投影约定决定；不得直接照搬不兼容的图形 API 公式。
- 弧度与角度、世界/相机/屏幕空间、点与方向、单位与维度、浮点容差，代码中必须显式命名。
- 算法正确优先于渲染速度和工程复杂度；每次新增一种功能都应尽可能有小型确定性测试。

## 5. 进度变更政策

- 状态的唯一可信记录：`docs/LEARNING_PROGRESS.md`；每课详见 `docs/lessons/LXX_*.md`，个人推导可写到 `docs/notes/`。
- 学习顺序可以微调，但 Agent 必须先说明**原因及依赖变化**，经学生同意后才改本教学计划。
- 一次课未完成时，下次继续**同一课**；不要因聊天轮次、日期或“看起来差不多”而自动升级。
- 如基础不足，优先补一个服务于当前主题的 15–30 分钟微练习，不为了琐碎 API 新增主课程章节。
