# CGLab 进度维护技能

1. 阅读 `AGENTS.md`、`docs/PROGRESS_MAINTENANCE.md` 与 `docs/LEARNING_PROGRESS.md`，不要用聊天印象替代文档。
2. 检查当前课的作品、测试与解释是否有可验证依据；区分 `planned` / `user_reported` / `observed`。
3. 状态限 `not_started`、`in_progress`、`blocked`、`review`、`completed`；不自动升级至 `completed`。
4. 更新进度时保留已有历史、当前课程 ID 和卡点；`Next Action` 保持为一个最小可执行任务。
5. 若无权编辑仓库，提供建议变更文本并明确标记“尚未写入”；不得谎称已更新。
6. 不重置、丢弃或覆盖学生代码与 Git 历史；外部同步操作先确认用户授权。
7. 在回复末尾简洁反馈实际发生的进度变更，或标记未满足的验收事项。

详细状态与证据规则只参照 `docs/PROGRESS_MAINTENANCE.md`。
